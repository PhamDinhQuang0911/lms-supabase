Hướng dẫn lấy Gemini API Key miễn phí (Chỉ mất 30 giây):
  1. Truy cập Google AI Studio (Bấm vào đây) và đăng nhập Gmail.
  2. Bấm nút "Create API Key" (Tạo khóa API).
  3. Copy chuỗi khóa API (bắt đầu bằng AIzaSy...) và dán vào ô bên dưới.
* Google cấp hạn ngạch hoàn toàn miễn phí cho tài khoản cá nhân.
