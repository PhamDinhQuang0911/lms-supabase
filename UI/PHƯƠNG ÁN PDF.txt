# LMS Exam Preview & PDF Export - Phase 1 Specification

## 1. Mục tiêu

Hệ thống LMS hiện tại đã có chức năng:

- Quản lý ngân hàng câu hỏi toán học.
- Import câu hỏi dạng LaTeX.
- Lưu nội dung câu hỏi.
- Render công thức toán bằng MathJax trên giao diện web.
- Cho phép người dùng lựa chọn câu hỏi để tạo đề thi.

Mục tiêu Phase 1:

Xây dựng chức năng:

1. Preview đề thi dạng chuẩn A4.
2. Hiển thị đề thi với form giống đề thi thực tế.
3. Render đầy đủ:
   - Nội dung câu hỏi.
   - Công thức toán.
   - Hình ảnh.
   - Đáp án.
   - Lời giải (nếu có).
4. Cho phép người dùng xuất PDF bằng chức năng Print của trình duyệt.

# 10. MathJax Processing

Input:

```
Latex
```

Ví dụ:

```
$x^2+y^2=z^2$
```

Output:

```
Công thức toán đã render
```

Yêu cầu:

* Không hiển thị Latex raw.
* Không xuất PDF khi MathJax chưa hoàn thành.
* Công thức không bị vỡ.

Flow:

```
Load Exam Page

↓

Render HTML

↓

MathJax Typeset

↓

Check Complete

↓

Allow Print

```
